# cloudlab-infra-ops
クラウド環境におけるWebサーバーの運用保守を行う自主学習プロジェクトです。<br>
資格取得の過程で学習したネットワーク,Linux,Azure知識のアウトプットとして作成しています。<br>
Azureの各種サービスを使用したネットワーク設定、監視、障害対応に取り組むことを目的としています。<br>

# 使用技術
- Azure 
    - Azure Virtual Machines 
    - NSG
    - Virtual Network（VNet）
    - Azure Monitor
    - Log Analytics
    - Alert Rules
- Ubuntu Server 24.04 LTS
- nginx
